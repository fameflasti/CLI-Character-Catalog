# дизайн-документ: консольний інтерфейс (каталог персонажів)

## 1. про що проєкт
це консольна програма для роботи з каталогом персонажів
через команди в терміналі можна подивитися список героїв, відкрити детальну інформацію про кожного та додати нового персонажа

## 2. як влаштований код
програма розділена на дві частини, щоб все не було разом:
* **DomainLayer** тут лежить клас `CharacterModel` це модель персонажа
* **CliLayer** тут знаходиться вся логіка роботи з консоллю

## 3. які патерни використано
* **фасад (`CliFacade`)** головний клас, через який запускається і працює весь інтерфейс 
він приховує внутрішню роботу парсера і пошуку по списку, щоб у `Main` було мінімум коду
* **стратегія (`ICommandStrategy`)** щоб не робити один великий `switch` для всіх команд, є окремі класи:
  * `InformationStrategy` для перегляду
  * `ManagementStrategy` для додавання і збереження
  так легше додавати нові команди в майбутньому, не чіпаючи старий код
* **інтерфейс рендеру (`IRenderer`)** вивід у консоль винесено в окремий клас `ConsoleRenderer`, щоб команди не викликали `Console.WriteLine` напряму

## 4. як працюють команди
коли користувач щось вводить, клас `Args` розбиває цей рядок на саму команду та аргумент після неї
далі фасад знаходить потрібну стратегію і виконує її
